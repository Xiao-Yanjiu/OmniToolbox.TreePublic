# 幻化管理增强

保留 `BetterGlamourManagement` 模块入口、宿主构造参数及原配置路径。在选择方案时显示独立预览；试衣间作为隐藏的原生渲染后端，不需要先将方案应用到场景角色。

- 预览支持装备、染色、发型、眼镜／面部装饰，原生控制按钮、左拖旋转、右拖平移和滚轮缩放。
- 剪贴板导入创建新方案，导出当前方案；还原外观按钮撤销场景角色上的试穿覆盖。
- 原方案增加稳定 `Id`，启用时保存迁移结果，保留原有装备与套装绑定数据。
- 手机接口提供方案同步、编辑、搜索、试穿、还原、相机控制及 JPEG 帧缓存。详见 [IPC 文档](../../IPC/GlamourManagement.md)。手机 App 和网络服务端不在此模块中。

## 渲染与生命周期

复用原生 TryOn 后端，隐藏和关闭通过原生 UI 生命周期处理。模块停用会注销接口、取消取帧及释放持有资源。游戏纹理读取使用 Dalamud SDK 的原始像素读取接口；缩放和 JPEG 编码在 CPU 后台执行，同一时刻只处理一个取帧任务。预览不使用游戏画面串流的编码器或进程；人物渲染与纹理读取仍依赖游戏图形设备。

本实现针对当前国服原生结构、Dalamud CN API 15 和 KamiToolKit TextureImageNode。原生结构变化后需要重新核对偏移及生命周期。30 FPS 为取帧调度目标，实际帧率受硬件、SDK 读回及网络影响。

## 验证

模块隔离编译与托管检查见 [测试说明](../../Tests/BetterGlamourManagement/README.md)。用户已实机确认手机预览与游戏画面串流并发运行稳定；这属于该用户环境的验证结果。

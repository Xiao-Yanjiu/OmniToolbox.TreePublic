# 库存与收录

返回格式见 [调用约定](调用约定.md)。`itemID` 使用基础物品 ID，品质由返回的 `hq` 区分。

## 库存

| IPC | 参数 | 返回内容 |
| --- | --- | --- |
| `OmniToolbox.Inventory.GetItem` | `uint itemID, string scope, ulong contentID, bool includeCached` | 数量、角色与物品来源 |
| `OmniToolbox.Inventory.GetCharacters` | 无 | `characters`、`houses`、`revision`、`currentCharacterContentID`、`liveReady` |

| `scope` | `contentID` | 范围 |
| --- | --- | --- |
| `currentCharacter` | `0` | 当前角色 |
| `allCharacters` | `0` | 全部已缓存角色 |
| `character` | 非 `0` | 指定角色 |

范围忽略大小写，独立于界面筛选。`includeCached=false` 仅包含当前角色已就绪的背包、兵装库与装备扫描；`true` 包含离线角色、雇员及上架、鞍囊、幻化台、收藏柜、部队箱和住宅缓存。

`GetItem` 返回 `ready`、`liveReady`、`revision`、`character`、`observedNQ`、`observedHQ`、`observedTotal`、`items`、`houses`。未就绪的数量为 `null`，`complete=false` 表示未保证所有容器均已采集。

### 来源字段

| 字段 | 含义 |
| --- | --- |
| `quantity`、`hq` | 数量、品质 |
| `source`、`sampledAtUTC` | `live` / `cache`；快照采集时间，未知为 `null` |
| `location` | `Inventory`、`Armory`、`Equipped`、`Saddlebag`、`Retainer`、`RetainerMarket`、`GlamourDresser`、`Armoire`、`FreeCompanyChest`、`HousingStoreroom` |
| `containerType`、`containerID`、`slotIndex` | 容器名称、枚举值与槽位 |
| `holderID`、`holderName` | 持有者，例如雇员 |
| `ownerContentID`、`ownerName`、`ownerWorldID` | 快照所属角色 |
| `stain0`、`stain1`、`housing` | 染料与住宅来源 |

住宅提供 `houseID`、`estateType`、`characterContentIDs`、`worldID`、`territoryTypeID`、`wardNumber`、`plotNumber`、`roomNumber`、`apartmentDivision`、`plotSize`。类型为 `PersonalEstate`、`FreeCompanyEstate`、`ApartmentRoom`、`PersonalChambers` 或 `Unknown`。

`area` 区分 `interior` / `exterior`，`storage` 区分 `storeroom` / `placed`。`houses[].sources` 保留已采集的空容器；共享住宅按房屋 ID 去重。部队箱按角色保存，全角色合计可能包含同一共享箱的多份快照。

采集时间随缓存保存，查询不更新时间。缓存可能过期，零数量不代表未采集容器中没有物品。

## 收录

| IPC | 参数 | 返回内容 |
| --- | --- | --- |
| `OmniToolbox.Collection.GetItem` | `uint itemID` | `ready`、`tracked`、`entries` |
| `OmniToolbox.Collection.GetProgress` | `string type` | `total`、`knownUnlocked`、`unknown`、`known`、`unlocked` |

`entries` 包含 `id`、`type`、`name`、`known`、`unlocked`。状态未知时 `unlocked=null`；`tracked=false` 表示没有对应收录条目。

分类支持 `Equipment`、`Mount`、`Minion`、`Emote`、`Hairstyle`、`TripleTriadCard`、`Barding`、`Orchestrion`、`Portrait`、`FashionAccessory`、`Glasses`、`BlueMageSpell`、`BlindBox`、`Bestiary`，忽略大小写。

```csharp
var inventory = await pluginInterface.GetIpcSubscriber<uint, string, ulong, bool, Task<string>>(
    "OmniToolbox.Inventory.GetItem").InvokeFunc(itemID, "allCharacters", 0UL, true);
```

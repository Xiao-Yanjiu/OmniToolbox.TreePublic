# 模块

返回格式见 [调用约定](调用约定.md)。

## 启停

| IPC | 参数 | 返回内容 |
| --- | --- | --- |
| `OmniToolbox.Module.GetList` | 无 | `modules`：模块内部名数组 |
| `OmniToolbox.Module.GetStatus` | `string moduleName` | 模块状态 |
| `OmniToolbox.Module.SetEnabled` | `string moduleName, bool enabled, bool affectConfig` | `accepted` 与模块状态 |

名称支持内部名和简繁中文标题，不区分大小写；建议使用 `GetList` 返回的内部名。

模块状态包括 `module`、`enabled`、`configuredEnabled`、`temporary`、`canEnable`、`reason`。实际运行状态和保存的开关分别由 `enabled` 与 `configuredEnabled` 表示。

`affectConfig=true` 保存开关；`false` 仅临时启停。临时状态在模块或插件重载后清除，仍受验证限制。

## 自动化操作

| IPC | 参数 | 返回内容 |
| --- | --- | --- |
| `OmniToolbox.Automation.GetStatus` | `string moduleName` | 模块状态及 `supported`、`actions`、`busy`、`state` |
| `OmniToolbox.Automation.Start` | `string moduleName, string action, string arguments` | `accepted` 与当前状态 |
| `OmniToolbox.Automation.Stop` | `string moduleName` | `accepted` 与当前状态 |

动作不区分大小写；无参数时传空字符串。`action` 最长 64 字符，`arguments` 最长 4096 字符。忙碌时拒绝新操作，`Stop` 不关闭模块总开关。

| 模块 | 动作 | 参数 / 行为 |
| --- | --- | --- |
| `ItemManagement` | `run` | 空；按已记忆物品执行一次出售或丢弃 |
| `AutoGCSeal` | `open`、`start`、`supply`、`exchange` | 空；打开助手、自动筹备兑换、打开筹备、打开兑换 |
| `AutoIslandSanctuary` | `open`、`enter`、`workshop`、`pasture`、`farm` | 空；面板、前往无人岛、工房界面、牧场管理、耕地管理 |
| `SpecialScenarioExplorer` | `open` | 空；打开探索窗口 |
| `SpecialScenarioExplorer` | `start` | `bozja` / `zadnor`；启动对应区域探索 |

探索也接受简繁中文全名。无人岛是否提供以当前构建的模块列表为准。这类持续自动化通过 `busy` 和 `state` 查询运行状态，不提供单次成功证明。

```csharp
var enabled = await pluginInterface.GetIpcSubscriber<string, bool, bool, Task<string>>(
    "OmniToolbox.Module.SetEnabled").InvokeFunc("SpecialScenarioExplorer", true, false);

var started = await pluginInterface.GetIpcSubscriber<string, string, string, Task<string>>(
    "OmniToolbox.Automation.Start").InvokeFunc("SpecialScenarioExplorer", "start", "bozja");
```

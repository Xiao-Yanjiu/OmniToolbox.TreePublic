# 传送

对应模块：`BetterTeleportManagement`。返回格式与请求状态见 [调用约定](调用约定.md)。

| IPC | 参数 | 返回内容 |
| --- | --- | --- |
| `OmniToolbox.Teleport.Start` | `string destination` | `accepted`、`operationID` |
| `OmniToolbox.Teleport.GetStatus` | 无 | `canExecute`、`busy`、`housingPlotTravel`、`operation` |
| `OmniToolbox.Teleport.GetOperation` | `string operationID` | `found`、`operation` |
| `OmniToolbox.Teleport.Cancel` | `string operationID` | `accepted`、`operationID` |

目的地使用水晶名称或 `Aetheryte` 表 ID，最长 4096 字符；支持原有城内以太网。ID 不是区域 ID。

普通传送需观察到目的区域及水晶落点才报告 `Succeeded`；无法确认时为 `Unconfirmed`。取消不会撤回原生读条。

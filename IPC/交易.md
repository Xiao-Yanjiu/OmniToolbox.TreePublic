# 交易

返回格式与请求状态见 [调用约定](调用约定.md)。物品使用基础 ID，数量为正数。

## 市场板

对应模块：`VoidPurchase`。

| IPC | 参数 | 返回内容 |
| --- | --- | --- |
| `OmniToolbox.Market.StartSearch` | `uint itemID` | `accepted`、`operationID` |
| `OmniToolbox.Market.StartPurchase` | `uint itemID, bool? isHQ, uint quantity, int maxUnitPrice` | `accepted`、`operationID` |
| `OmniToolbox.Market.GetStatus` | 无 | `canExecute`、`canPurchaseInCurrentArea`、`busy`、`searchItemID`、`statusKey`、`operation` |
| `OmniToolbox.Market.GetResult` | `string operationID` | `matchesSearch`、`dataReady`、`listings`、`history`、`operation` |
| `OmniToolbox.Market.GetOperation` | `string operationID` | `found`、`operation` |
| `OmniToolbox.Market.Cancel` | `string operationID` | `accepted`、`operationID` |

`isHQ=true` 仅 HQ，`false` 仅 NQ，`null` 不限品质。`maxUnitPrice>=0`，`0` 表示不限价；实际购买沿用模块配置及可购买区域限制。

`GetResult` 仅返回该 ID 对应的当前搜索。`dataReady=true` 时可读挂单与历史；后续搜索或购买可能替换数据，请求终态仍可按 ID 查询。

挂单包含 `listingID`、`itemID`、`unitPrice`、`quantity`、`totalTax`、`isHQ`、`townID`、`retainerName`；历史包含 `unitPrice`、`quantity`、`isHQ`、`purchaseTime`、`buyerName`。

## NPC 商店

对应模块：`VoidNPCShop`。

| IPC | 参数 | 返回内容 |
| --- | --- | --- |
| `OmniToolbox.NPCShop.GetSources` | `uint itemID` | `state`、`sources` |
| `OmniToolbox.NPCShop.StartPurchase` | `uint itemID, uint quantity, uint vendorID` | `accepted`、`operationID` |
| `OmniToolbox.NPCShop.GetStatus` | 无 | `canExecute`、`busy`、`statusKey`、`operation` |
| `OmniToolbox.NPCShop.GetOperation` | `string operationID` | `found`、`operation` |
| `OmniToolbox.NPCShop.Cancel` | `string operationID` | `accepted`、`operationID` |

`vendorID` 使用 NPC 基础数据 ID，`0` 自动选择。来源状态为 `Building`、`Ready`、`NotFound`、`Failed`、`Unavailable`、`InvalidRequest`；`sources` 包含 `vendorID`、`name`、`shopName`、`costs` 和 `location`。

`costs` 包含 `itemID`、`quantity`、`collectability`；`location` 包含 `territoryID`、`mapID`、`mapX`、`mapY`。季节活动商店不列入来源。

```csharp
var purchase = await pluginInterface.GetIpcSubscriber<uint, uint, uint, Task<string>>(
    "OmniToolbox.NPCShop.StartPurchase").InvokeFunc(itemID, 1U, 0U);
```

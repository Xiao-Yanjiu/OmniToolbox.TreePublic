# 自动存取

对应模块：`AutoStore`。返回格式与请求状态见 [调用约定](调用约定.md)。

| IPC | 参数 | 返回内容 |
| --- | --- | --- |
| `OmniToolbox.AutoStore.StartRetrieve` | `uint itemID, int quantity, bool? isHQ, string source, ulong holderID` | `accepted`、`operationID` |
| `OmniToolbox.AutoStore.StartStore` | `uint itemID, int quantity, bool? isHQ, string destination` | `accepted`、`operationID` |
| `OmniToolbox.AutoStore.StartRefreshCache` | `string target` | `accepted`、`operationID` |
| `OmniToolbox.AutoStore.GetStatus` | 无 | `canExecute`、`busy`、`canRefreshCache`、`operation` |
| `OmniToolbox.AutoStore.GetOperation` | `string operationID` | `found`、`operation` |
| `OmniToolbox.AutoStore.Cancel` | `string operationID` | `accepted`、`operationID` |

`itemID` 为基础物品 ID，`quantity>0`。`isHQ=true` 仅 HQ，`false` 仅 NQ，`null` 不限品质。

| 参数 | 可选值 |
| --- | --- |
| `source` | `None`、`Saddlebag`、`Armory`、`Retainer`、`GlamourDresser`、`Armoire`、`FreeCompanyChest` |
| `destination` | `Saddlebag`、`Armory`、`GlamourDresser`、`Armoire`、`FreeCompanyChest`、`Retainer1` 至 `Retainer10` |
| `target` | `Retainer`、`GlamourDresserAndArmoire`、`FreeCompanyChest` |

容器名称不区分大小写，最长 64 字符。`source=None` 自动选择来源；非零 `holderID` 只用于指定 `Retainer` 雇员。数量未完成会报告失败，无法确认数量的流程为 `Unconfirmed`。

```csharp
var request = await pluginInterface.GetIpcSubscriber<uint, int, bool?, string, ulong, Task<string>>(
    "OmniToolbox.AutoStore.StartRetrieve").InvokeFunc(itemID, 1, false, "Retainer", retainerID);
```
